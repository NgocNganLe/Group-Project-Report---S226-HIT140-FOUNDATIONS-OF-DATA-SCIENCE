# Model 2.1 report-aligned update — working snapshot



## Current primary analysis
-104 matches; eight numeric predictors from data/model 21_master.csv.
-Outcome: first-listed Team A minus Team B goal difference.
-Full-sample OLS with HC 3 standard errors and normal/z inference.
-CV: custom default_rng seed 42, five folds, three repetitions; mean per-fold RMSE.
-Each match remains a single Model 2.1 unit. This is resampling, not strict temporal forecasting.
-R 2/adjustedR 2 are explicitly in-sample. Do not substitute them for CVR 2.
-The older group 72→knockout 32 evaluation is a different experiment, not the primary result of the latest short report. Do not overwrite historical results with this bundle.

## Run
Use a Python environment compatible with the versions recorded in outputs/REPRODUCTION_AUDIT.json. From this bundle’s root:

```bash
python -m pip install -r requirements.txt
python scripts/run_model 21.py
```

The analysis itself runs offline against the two included snapshots. It does not download stadium coordinates, results or rankings; it does not rebuild all upstream features. It reads inputs without changing them and regenerates files within its own outputs folder.
